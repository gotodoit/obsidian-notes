## 7. [github/gh-stack](https://github.com/github/gh-stack)
- **语言**: Go
- **Stars**: 825
- **简介**: GitHub Stacked PRs

### AI 总结
**简介**: gh-stack 是一个 GitHub CLI 扩展，用于管理堆叠式分支和拉取请求，将大型变更拆分为一系列相互依赖的小型可评审 PR。

**核心功能**:
- **堆栈初始化**: 通过 `gh stack init` 创建新堆栈，支持交互式提示或指定分支列表，可自定义 trunk 基础分支
- **分支管理**: 使用 `gh stack add` 在堆栈顶部添加新分支，支持自动生成分支名（日期+slug格式）及提交变更（`-A`/`-u`/`-m` 选项）
- **堆栈操作**: 提供 `push`、`view`、`submit` 等命令，一键推送所有分支、查看堆栈结构、批量创建关联 PR
- **智能导航**: 支持 `up`、`down`、`top`、`bottom` 等导航命令，按堆栈层级快速切换分支
- **PR 自动链接**: 提交时自动为每个分支创建 PR，并正确设置 base 分支为下层分支，确保评审者只看到该层级的 diff
- **多方式检出**: 通过 `gh stack checkout` 支持按堆栈编号、PR 编号、PR URL 或分支名检出指定堆栈

**技术亮点**:
- 基于 Go 语言开发，作为 GitHub CLI 扩展分发
- 堆栈元数据存储在 `.git/gh-stack` JSON 文件中（不入库），中断 rebase 状态单独存储
- 自动启用 `git rerere` 记忆冲突解决方案，简化 rebase 过程
- 提供 AI agent 集成技能安装（`gh skill install`），便于 AI 编码助手理解堆栈 PR 工作流
